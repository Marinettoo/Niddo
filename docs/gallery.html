En marcha en 5 minutos

Un script bash lo configura todo automáticamente en cualquier servidor Linux. Sin tocar ficheros de configuración ni instalar dependencias a mano.

Requisitos mínimos

Servidor

  • Linux: Debian 12 o Ubuntu 24.04 LTS
  • 2 GB de RAM · 20 GB de disco mínimo
  • Acceso root (VPS, Raspberry Pi 4, mini-PC…)
  • Apache, PHP y MariaDB — el instalador los gestiona

Clientes Windows

  • Windows 10 o Windows 11
  • Python 3.x instalado
  • Conexión a la misma red que el servidor
  • El agente se descarga directamente desde el panel

Cómo empezar

1

Clona el repo

Descarga Niddo desde GitHub y ejecuta el instalador como root. Configura Apache, PHP y MariaDB solo.

git clone https://github.com/Marinettoo/Niddo
cd Niddo && sudo bash install.sh
2

Crea tu cuenta

Accede al panel web con la IP del servidor y crea la cuenta de administrador principal. Solo se hace una vez.

3

Añade dispositivos

Crea un dispositivo por cada PC Windows desde el panel. Se genera automáticamente el agente Python listo para ese equipo.

4

Ejecuta el agente

Descarga el agente en tu PC Windows y ejecútalo. Selecciona las carpetas a proteger y las copias arrancan solas.
