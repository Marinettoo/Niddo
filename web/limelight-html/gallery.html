En marcha en 5 minutos

Un script bash lo configura todo automáticamente en cualquier servidor Linux. Sin tocar ficheros de configuración ni instalar dependencias a mano.

Requisitos mínimos

Servidor

  • Linux: Debian 12 o Ubuntu 24.04 LTS
  • 2 GB de RAM · 20 GB de disco mínimo
  • Acceso root (VPS, Raspberry Pi 4, mini-PC…)
  • Apache, PHP y MariaDB — el instalador los gestiona

Clientes Windows

  • Windows 10 o Windows 11
  • Python 3.x instalado
  • Conexión a la misma red que el servidor
  • El agente se descarga directamente desde el panel

Cómo empezar

1

Clona el repositorio

Clona el repo de Niddo desde GitHub y ejecuta el instalador como root. El script configura Apache, PHP, MariaDB y Niddo automáticamente.

git clone https://github.com/Marinettoo/Niddo
cd Niddo && sudo bash install.sh
2

Crea tu cuenta

Accede al panel web desde el navegador e introduce la dirección IP del servidor. Crea la cuenta de administrador principal. Solo se hace una vez.

3

Añade dispositivos

Desde el panel, crea un dispositivo para cada PC Windows que quieras proteger. El panel genera automáticamente el agente Python listo para ese dispositivo.

4

Ejecuta el agente

Descarga el agente en tu PC Windows y ejecútalo. Selecciona las carpetas que quieres copiar y las copias empezarán automáticamente. Puedes programarlo con el Programador de tareas de Windows.

Precios transparentes

Empieza gratis. Paga solo si necesitas soporte o más dispositivos.
